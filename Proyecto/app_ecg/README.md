# Clasificador de senales ECG (Sano / Patologico)

Aplicacion web en Streamlit que clasifica registros de ECG usando las
derivaciones I, II y III mediante un modelo Random Forest.

## Instalacion

    python -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements.txt

## Ejecucion

    streamlit run app.py
